# 🎬 SafePlayer | مشغل الوسائط الآمن والذكي

تطبيق مشغل وسائط لنظام أندرويد (Android) مبني باستخدام Jetpack Compose و Material Design 3، مع أدوات للتحكم بالوسائط والخصوصية والحماية العائلية.

---

## 🚀 بناء APK وإعداد التوقيع بأمان

- تُشغّل Pull Requests عمليات الاختبار وبناء نسخة Debug.
- تُبنى نسخة Release فقط عند إعداد أسرار التوقيع في GitHub Actions.
- أضف هذه الأسماء إلى GitHub Actions Secrets: RELEASE_KEYSTORE_BASE64 وSTORE_PASSWORD وKEY_ALIAS وKEY_PASSWORD.
- لا ترفع ملفات JKS أو نسخ Base64 إلى المستودع. أزيلت ملفات التوقيع من النسخة الحالية من الكود.
- سبق أن كان مفتاح توقيع في تاريخ هذا المستودع العام؛ اعتبره مكشوفًا. حذف الملف من الفرع لا يزيله من commits السابقة. دوّر/أعد ضبط مفتاح الرفع في Play Console عند الاقتضاء، وأنشئ مفتاحًا جديدًا قبل إصدار نسخة جديدة.
- دون أسرار التوقيع، ستبني Actions نسخة Debug فقط؛ طلب إصدار Release يفشل عمدًا حتى لا تُوقّع النسخة بمفتاح افتراضي.

## 🌟 أبرز مميزات التطبيق (Features)

### 1. 🎚️ موازن الصوت المتقدم ومضخم الصوت (5-Band Equalizer & Loudness Enhancer)
- موازن ترددات خماسي دقيق (60Hz, 230Hz, 910Hz, 3.6kHz, 14kHz).
- أوضاع صوتية جاهزة: سينما 🎬، بودكاست 🎙️، موسيقى 🎵، تضخيم الباس 🔊، روك 🎸، وكلاسيك 🎻.
- شريط تحكم بتضخيم الباس الجهوري (Bass Boost).
- شريط مضاعفة ورفع مستوى الصوت للأجهزة ومقاطع الفيديو منخفضة الصوت (Loudness Boost).

### 2. 📝 دعم وتخصيص الترجمة الخارجية (External SRT / VTT Subtitles)
- تحميل أي ملف ترجمة خارجي بصيغة `.srt` أو `.vtt` من ذاكرة الهاتف.
- مزامنة توقيت الترجمة الفورية بالثواني والأجزاء (`-0.5s` إلى `+0.5s`).
- تخصيص حجم الخط، ولون الترجمة (أبيض، أصفر، سماوي، أخضر)، ودرجة شفافية الخلفية.
- إمكانية تشغيل ترجمة تجريبية باللغة العربية بلمسة واحدة.

### 3. 🔐 الخزنة السرية المتقدمة (Safe Vault Pro)
- إخفاء عناصر محددة من مكتبة SafePlayer. هذا لا يشفّر الملفات الأصلية ولا يخفيها من تطبيقات المعرض الأخرى.
- فتح الخزنة بواسطة **البصمة (Biometrics)** أو **الرمز السري (PIN)**.
- **وضع التمويه الذكي (Decoy PIN) 🕵️**: عند إدخال الرمز البديل، يفتح التطبيق خزنة وهمية فارغة تماماً لحماية الخصوصية في حال التطفل.
- حماية ضد تصوير الشاشة وتسجيل الفيديو (`FLAG_SECURE`).

### 4. 📸 لقطة شاشة فورية وفلاتر الفيديو المباشرة (Instant Snapshot & Live Filters)
- **لقطة شاشة فورية 📸**: استخراج الإطار الحالي من الفيديو بدقة فائقة وحفظه مباشرة في مجلد الصور (`Pictures/SafePlayer`).
- **فلاتر بصرية مباشرة 🎨**: تعديل فوري لدرجة الإضاءة (Brightness)، التباين (Contrast)، وتشبع الألوان (Saturation)، مع فلاتر جاهزة مثل (سينما HDR، ألوان زاهية، حماية العين الدافئة، وأبيض وأسود).

### 5. 🛡️ الحارس العائلي والمشاهدة الآمنة (Smart Safe-Watch & Family Guard)
- إضافة قواعد حماية آلية على الشريط الزمني:
  - **تخطي تلقائي (Auto-Skip)**: القفز فوق المشهد غير المرغوب تلقائياً.
  - **كتم صوت تلقائي (Auto-Mute)**: كتم الصوت مؤقتاً في الثواني المحددة ثم استعادته.
  - **تعتيم بصري (Auto-Blur Shield)**: تعتيم الشاشة وحجب المشهد بدرع حماية عائلي.
- توليد قواعد حماية ذكية، ومشاركة وتصدير ملفات الحماية بصيغة `.safeplay`.

### 6. 📱 تجربة المشغل الذكية (Player Essentials)
- مشغل مصغر عائم (Mini-Player Bar) في الشاشة الرئيسية.
- نافذة عائمة مصغرة (Picture-in-Picture - PiP).
- تكبير وتحريك الفيديو بحرية باللمس بالأصابع (Pinch-to-zoom من 100% إلى 400%).
- نقر مزدوج للتقديم والترجيع (10 ثوانٍ يميناً ويساراً).
- تكرار مقطع محدد A-B Repeat، وحفظ علامات مرجعية زمنية (Bookmarks).
- مؤقت نوم ذكي (Smart Sleep Timer) مع عد تنازلي حي وزر تمديد +5 دقائق.

### 7. 📡 المشاركة عبر Wi‑Fi (Wi-Fi Transfer)
- اقتران برمز عشوائي، واستبعاد عناصر الخزنة والتحقق من الصلاحية عند فتح كل ملف.
- يمكن رفع ملفات حتى 100 MB؛ استخدم شبكة موثوقة فقط، لأن اتصال HTTP المحلي غير مشفّر.

## 🛠️ البناء المحلي (Local Build)

~~~bash
# استنساخ المستودع
git clone https://github.com/malkbaty7-sketch/SafePlayer521.git
cd SafePlayer521

# تشغيل الاختبارات وبناء نسخة Debug
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug

# يتطلب بناء Release إعداد متغيرات البيئة KEYSTORE_PATH وSTORE_PASSWORD وKEY_ALIAS وKEY_PASSWORD
./gradlew :app:assembleRelease
~~~

ملفات APK تكون في مسارات البناء المعتادة داخل app/build/outputs/apk/.
